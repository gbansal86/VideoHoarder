# VideoHoarder Future Requests

This folder is the authoritative location for proposed VideoHoarder work that has not yet been implemented.

Files use a `YYYY-MM-DD_` prefix so their origin and order remain clear.

- `2026-08-14_Pending_Updates_Backlog.md` — general remaining application improvements and reusable request templates.
- `2026-08-15_Central_Artifact_Manifest_System.md` — central, incrementally updated inventory and change-history system.
- `VideoHoarder_Future_Requests_Editor.html` — colorful browser editor containing both current future-request documents, with local autosave, independent accent/background palettes, reset, print and export controls.

Open the HTML editor directly in a modern browser. Browser edits are stored in that browser's local storage; use its export controls to create portable files.

Adding or editing a document here does not authorize implementation. Coding begins only after the user explicitly requests it.
