P588 [Heading 1]: 76. Optional ChatGPT Perspective (PS) — Separate from Source-Grounded Intelligence
P589 [Normal]: The uploaded baseline specification explicitly allows ChatGPT to provide its own take on the video at the end. Implement this as an optional, clearly separated field so it can never be mistaken for transcript-derived evidence or authoritative source metadata.
P590 [Normal]: "chatgpt_perspective_ps": {
  "take": "",
  "interesting_observations": [],
  "questions_to_consider": [],
  "possible_gaps_or_caveats": [],
  "label": "CHATGPT PERSPECTIVE / NOT SOURCE-EXTRACTED FACT"
}
P591 [List Bullet]: This field is optional and may be empty when no useful additional perspective exists.
P592 [List Bullet]: It must be visually and structurally separated from executive_summary, detailed_summary, facts, claims, recommendations, warnings, and transcript evidence.
P593 [List Bullet]: It must never overwrite source metadata, transcript-derived intelligence, manually locked fields, or evidence-backed facts.
P594 [List Bullet]: Knowledge Center/search may expose it only when clearly labeled as ChatGPT perspective; it should not outrank transcript-derived evidence.
P595 [List Bullet]: If the package requests strict source-only analysis, this field may contain source-grounded interpretation only. If broader commentary is allowed, the output must explicitly label any non-source inference as ChatGPT commentary.
P596 [List Bullet]: Do not place free-form prose outside the machine-readable result when the package expects JSON; keep the PS inside the structured result.
