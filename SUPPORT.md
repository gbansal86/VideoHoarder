# Support

For reproducible bugs, open a GitHub issue using the bug template and include:

- VideoHoarder version;
- Windows/Python version when running from source;
- exact action/workflow;
- expected vs actual result;
- sanitized error/log excerpt;
- whether the issue reproduces with a small test library.

Never include API keys, cookies, OAuth tokens, private/unlisted video details, or personal filesystem information that is not necessary to reproduce the problem.

Security vulnerabilities belong in the private channel described in `SECURITY.md`, not a public support issue.
